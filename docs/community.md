# Deel 1: Community

Een plek waar huidige teams vragen kunnen stellen aan **alumni-Humasolers** die al eerder aan een gelijkaardig project werkten.

## Kanalen per type project

| Kanaal | Voor wie? |
|---|---|
| `#pv` | Vragen over zonne-installaties |
| `#waterdistributie` | Pompen, opslag, leidingnetten |
| `#biogas` | Vergisters en gasgebruik |
| `#waterfiltratie` | Filtratie en desinfectie |
| `#algemeen` | Alles wat niet in een kanaal past |

**Link om lid te worden:** *in te vullen (Slack- of WhatsApp-uitnodiging)*

## Afspraken

- Stel je vraag in het juiste kanaal, met je project en land erbij
- Is een antwoord nuttig voor iedereen? **Zet het daarna in de library**, anders gaat het verloren in de chat
- Alumni kiezen zelf in welke kanalen ze zitten

!!! tip "Van chat naar kennisbank"
    Vraag en antwoord die vaak terugkomen, horen op de pagina van de technologie. Zo groeit de library vanzelf.
