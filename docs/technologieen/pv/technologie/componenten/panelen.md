# Panelen

## Info component
Zetten zonlicht om in gelijkstroom (DC).

## Relevante parameters

| Parameter | Betekenis |
|---|---|
| Vermogen (Wp) | Piekvermogen onder standaardcondities |
| Rendement (%) | Hoeveel zonlicht wordt omgezet |
| Voc / Isc | Open klemspanning en kortsluitstroom, nodig voor de keuze van de laadregelaar |
| Temperatuurcoëfficiënt | Hoeveel vermogen je verliest bij hitte |

## Welke types + vergelijking

| Type | Voordelen | Nadelen |
|---|---|---|
| Monokristallijn | Hoogste rendement, compact | Iets duurder |
| Polykristallijn | Goedkoper | Lager rendement, minder gangbaar |

## Hoe dimensioneren

1. Bereken het dagelijkse verbruik in Wh
2. Zoek de zonuren (Peak Sun Hours) voor de locatie op
3. Benodigd vermogen ≈ verbruik ÷ zonuren ÷ verliesfactor
4. Richt panelen naar de evenaar, hellingshoek ≈ breedtegraad (minimum ±10°)
