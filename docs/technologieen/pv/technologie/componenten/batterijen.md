# Batterijen

## Info component
Slaan energie op voor 's nachts en bij bewolking.

## Relevante parameters

| Parameter | Betekenis |
|---|---|
| Capaciteit (Ah of kWh) | Hoeveel energie de batterij bevat |
| Ontladingsdiepte (DoD) | Hoeveel je mag gebruiken zonder schade |
| Aantal cycli | Levensduur |
| Spanning (V) | 12/24/48 V systeem |

## Welke types + vergelijking

| Type | Voordelen | Nadelen |
|---|---|---|
| Lood-zuur | Goedkoop, lokaal vaak te koop | Kortere levensduur, gevoelig voor diepe ontlading |
| Lithium (LiFePO4) | Lange levensduur, diepe ontlading mogelijk | Duurder in aankoop |

## Hoe dimensioneren

1. Dagverbruik × aantal dagen autonomie
2. Deel door de toegelaten ontladingsdiepte
3. Deel door de systeemspanning voor de capaciteit in Ah
