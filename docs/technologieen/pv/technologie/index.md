# B. Technologie: PV (zonne-energie)

## 1. Info

**Hoe hangt alles samen?**

```
Panelen → Omvormer → Batterijen → Laadregelaar
```

**Op Drive:**

- [Dimensioneringstool](https://drive.google.com/) *(link invullen)*
- [Centrale supplier list](https://drive.google.com/): één sheet voor alle landen en technologieën, filter op *PV (zonne-energie)* *(link invullen)*

## 2. Main componenten

Elk component heeft een eigen pagina met: info, relevante parameters, types + vergelijking en hoe dimensioneren.

| Component | Wat doet het? |
|---|---|
| [Panelen](componenten/panelen.md) | Zetten zonlicht om in gelijkstroom (DC). |
| [Omvormer](componenten/omvormer.md) | Zet de gelijkstroom van de batterijen om naar 230 V wisselstroom. |
| [Batterijen](componenten/batterijen.md) | Slaan energie op voor 's nachts en bij bewolking. |
| [Laadregelaar](componenten/laadregelaar.md) | Regelt het laden van de batterijen vanuit de panelen en beschermt ze tegen overladen. |
