# Hoe bijdragen

## Een pagina aanpassen (geen installatie nodig)

1. Klik bovenaan de pagina op het **potloodje** ✏️
2. Log in op GitHub (eenmalig een gratis account maken)
3. Pas de tekst aan
4. Klik onderaan op **Commit changes**
5. Na een paar minuten staat je wijziging online

## Een nieuwe pagina toevoegen

1. Ga op GitHub naar de juiste map in `docs/`
2. Klik op **Add file → Create new file**
3. Geef het bestand een naam die eindigt op `.md`, bijvoorbeeld `bekabeling.md`
4. Kopieer een [sjabloon](sjablonen/index.md) en vul het in
5. Voeg de pagina toe aan het menu in `mkdocs.yml`

## Markdown-spiekbriefje

| Je typt | Je krijgt |
|---|---|
| `# Titel` | Grote titel |
| `## Subtitel` | Kleinere titel |
| `- punt` | Opsommingsteken |
| `**vet**` | **vet** |
| `[tekst](link)` | Een klikbare link |
| `!!! tip "Titel"` + ingesprongen tekst | Een gekleurd tipkader |
