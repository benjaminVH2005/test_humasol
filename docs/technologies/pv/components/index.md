# C. Main components: PV (solar power)

For each component you find: **how it works**, **which types exist** and **how to size it**.

| Component | What does it do? |
|---|---|
| [Solar panels](panels.md) | Convert sunlight into direct current (DC). |
| [Inverter](inverter.md) | Converts the direct current (DC) from the batteries into 230 V alternating current (AC) for ordinary appliances. |
| [Batteries](batteries.md) | Store energy for the night and for cloudy days. |
| [Charge controller](charge-controller.md) | Controls how the batteries are charged from the panels and protects them against overcharging. |
