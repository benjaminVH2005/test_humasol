# B. Introduction to the technology: PV (solar power)

What you need to know before moving on to the [main components](components/index.md).

## How does the system fit together?

```
Solar panels → Inverter → Batteries → Charge controller
```

## Key terms

| Term | Meaning |
|---|---|
| kWp | Peak power of the panels under standard test conditions |
| kWh | Amount of energy (consumption or storage) |
