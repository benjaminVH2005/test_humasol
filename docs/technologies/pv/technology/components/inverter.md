# Inverter

## Info
Converts the direct current from the batteries into 230 V alternating current.

## Relevant parameters

| Parameter | Meaning |
|---|---|
| Continuous power (W) | What the inverter can always handle |
| Surge power (W) | For start-up currents of motors and pumps |
| Input voltage (V) | Must match the battery voltage (12/24/48 V) |
| Waveform | Pure or modified sine wave |

## Types + comparison

| Type | Advantages | Disadvantages |
|---|---|---|
| Pure sine wave | Suitable for all appliances | More expensive |
| Modified sine wave | Cheap | Problems with motors and sensitive electronics |
| Hybrid inverter | Charge controller and inverter in one | One fault stops everything |

## How to size it

1. Add up the power of all appliances that run at the same time
2. Add a 25 % margin
3. Check the surge power for appliances with a motor
