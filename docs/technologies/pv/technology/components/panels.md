# Solar panels

## Info
Convert sunlight into direct current (DC).

## Relevant parameters

| Parameter | Meaning |
|---|---|
| Power (Wp) | Peak power under standard test conditions |
| Efficiency (%) | How much of the sunlight is converted |
| Voc / Isc | Open-circuit voltage and short-circuit current, needed to choose the charge controller |
| Temperature coefficient | How much power you lose in the heat |

## Types + comparison

| Type | Advantages | Disadvantages |
|---|---|---|
| Monocrystalline | Highest efficiency, compact | Slightly more expensive |
| Polycrystalline | Cheaper | Lower efficiency, less common |

## How to size it

1. Calculate the daily consumption in Wh
2. Look up the peak sun hours for the location
3. Required power ≈ consumption ÷ peak sun hours ÷ loss factor
4. Face the panels towards the equator, tilt ≈ latitude (minimum ±10°)
