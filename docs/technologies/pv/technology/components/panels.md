# Solar panels

## Info
Convert sunlight into direct current (DC).

## Relevant parameters

| Parameter | Meaning |
|---|---|
| Power (Wp) | Peak power under standard test conditions |
| Voc / Isc | Open-circuit voltage and short-circuit current: needed to choose the charge controller |
| Temperature coefficient | Power loss in the heat: important in hot climates |
| Tilt and orientation | Facing the equator; on a roof, the roof slope often decides the tilt |

## Types + comparison

| Type | Advantages | Disadvantages |
|---|---|---|
| Monocrystalline | Highest efficiency, compact | Slightly more expensive |
| Polycrystalline | Cheaper | Lower efficiency, less common today |

Recent Humasol projects used **monocrystalline** panels.
