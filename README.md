# Humasol Knowledge Hub

The knowledge of Humasol, per country and per technology, built with [Zensical](https://zensical.org/).

- Pages: Markdown files in `docs/`
- Menu order: `nav` in `mkdocs.yml`
- Every change on `main` rebuilds and publishes the site automatically (`.github/workflows/main.yml`)
